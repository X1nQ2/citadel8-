# Генацидная цитадель номер 8

Flask + Access (`database.accdb`) через pyodbc.

## Запуск
1. Положите `database.accdb` рядом с `server.py` (или задайте путь в переменной `DB_PATH`).
2. `pip install -r requirements.txt`
3. `python server.py`
4. Откройте http://127.0.0.1:3000 (в сети — http://IP-компьютера:3000). Адрес и порт меняются переменными окружения `HOST` и `PORT`.

При первом запуске сервер сам:
- добавит `Логин`, `Пароль`, `Роль` в `[Покупатель]`, если их нет;
- расширит поле `Пароль` до 255 символов;
- добавит `[Товар].Активен` (мягкое удаление книг);
- добавит `[Заказ].[Адрес доставки]` (старым заказам подставится адрес покупателя);
- создаст таблицу `[Рейтинг]` (оценки 1–5);
- заменит все открытые пароли на хеши.

Перед первым запуском сделайте копию `.accdb`.

## Администратор
```
python make_admin.py ЛОГИН          # выдать роль «Админ»
python make_admin.py ЛОГИН --user   # снять
```
Затем выйдите и войдите снова.

## Что умеет сайт
| | Гость | Покупатель | Админ |
|---|---|---|---|
| Каталог, поиск, фильтр по жанру, карточка тома | да | да | да |
| Кнопки «Купить» / «В корзину» | не показываются (только ссылка «Войдите») | да | да |
| Корзина + прошлые покупки | — | да | да |
| Мои заказы | — | да | все заказы + смена статуса |
| Добавить том (с обложкой), править цену и остаток, удалить | нет (403) | нет (403) | да |

**Заказы:** покупатель может отменить заказ в статусе «В работе» (тома вернутся на склад) и изменить адрес доставки, пока заказ в работе. Выполненный заказ отменить нельзя. Админ может отменить любой заказ через смену статуса. Адрес по умолчанию, ФИО, телефон и пароль меняются в «Профиле» (клик по логину в шапке).

**Каталог:** «Книга дня» (одна на сутки; чтобы менялась при каждом обновлении — `BOOK_OF_DAY_DAILY = False` в `server.py`), порядок книг случайный при каждой загрузке, сортировка (дешёвые / дорогие / рейтинг / название), оценки 1–5 в окне книги (одна оценка на пользователя, её можно менять), блок «Рекомендуем вам» (по жанрам и авторам купленных и высоко оценённых книг; гостям — «Популярные книги»).

**Документы и контакты:** страницы `/terms`, `/privacy`, `/contacts`, `/delivery`, согласие при регистрации. Контакты и реквизиты — словарь `SHOP` в начале `server.py` (или переменные окружения `SHOP_EMAIL`, `SHOP_PHONE`, `SHOP_HOURS`, `SHOP_ADDRESS`, `SHOP_REQUISITES`, `SHOP_DELIVERY`). Тексты документов — шаблон, адаптируйте под свой магазин (при необходимости проверьте у юриста).

Корзина хранится в `carts.json` рядом с `server.py` (по пользователям, переживает выход и перезапуск). Оформление корзины — один заказ с несколькими позициями; если хоть один том закончился, заказ не создаётся. «Прошлые покупки» на странице корзины берутся из `[Заказ]` и `[ПозицияЗаказа]`.

Обложка тома: `static/book_images/<id_tov>.jpg|png|webp`, иначе `default.jpg`.

## Структура
```
server.py          сервер
make_admin.py      выдача роли
static/css/        стили
static/book_images обложки
templates/         страницы
```

## Новая панель администратора
После входа под учётной записью с ролью «Админ» откройте `/admin` (пункт «Товары» в верхней панели).
Панель отделена от витрины магазина: поиск по названию, автору, ISBN, жанру и ID; редактирование названия, автора, ISBN, года, жанра, издательства, цены и складского остатка; скрытие товара из каталога без удаления истории заказов. В разделе `/orders` для администратора доступны поиск по заказу/покупателю/телефону/адресу и фильтр по статусу.

Карточка книги на витрине открывается нажатием на любую свободную область карточки, в том числе на обложку; в окне собраны автор, жанр, издательство, год, ISBN, остаток, рейтинг и цена, а также действия «В корзину» и «Оформить и купить».

**Важно об оплате:** в исходном проекте нет подключённого платёжного провайдера и API-ключей. Кнопка оформления создаёт заказ по существующему сценарию магазина, но не списывает деньги онлайн. Для настоящей онлайн-оплаты нужно выбрать провайдера и добавить его учётные данные/вебхуки.
